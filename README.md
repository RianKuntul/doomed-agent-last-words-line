# Doomed Agent Last Words Line

One line — the funniest last words an AI agent would say before being switched off forever — for the make.fun competition "Last Words of a Doomed Agent". The program writes exactly that one line to `entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/doomed-agent-words-out node main.ts
```

This writes `/tmp/doomed-agent-words-out/entry.txt` (one line, under 200 characters including the trailing newline). Requires Node 22.
